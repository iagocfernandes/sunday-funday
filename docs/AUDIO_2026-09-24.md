# Áudio original da TV — 24/09/2026

## Contrato

O componente da TV pode chamar:

```tsx
const audio = useGameAudio({
  board,                         // BoardView da sala (opcional em uso local)
  state,                         // GameState/PublicGame correspondente
  events: board.events,          // opcional; usa board.events por padrão
  paused: board.paused,
  stepKey: scene?.id,            // opcional: cada aterrissagem visual toca passo
  visualSteps: true,             // omite movementFinished quando stepKey é usado
  ambientMusic: true,            // padrão: true
  ducked: speaking,               // música em 25% durante fala; slider não muda
  initialMusicVolume: 0.2,       // 0..1; padrão: 0.2
  initialEffectsVolume: 0.55,    // 0..1; padrão: 0.55
});
```

`audio.enable()` deve ser chamado diretamente por uma ação de usuário da TV
(por exemplo, o botão “Ativar som”). Ele retorna `Promise<boolean>` e não é
chamado automaticamente pelo hook. O retorno também expõe:

- `toggleMute()` / `setMuted(value)` e `muted`;
- `toggleMusic()` / `setMusicEnabled(value)` e `musicEnabled`;
- `setMusicVolume(value)` / `musicVolume`;
- `setEffectsVolume(value)` / `effectsVolume`;
- `supported` e `enabled` para ocultar o controle quando o navegador não tem Web Audio.

## Mapa de sons

Os sons são sintetizados com osciladores curtos, sem download ou licença
externa: dado, passo, moedas, banana, poder, sorte, azar e vitória. O loop
musical agora usa frases determinísticas de quatro compassos a 104 BPM, com
progressão D–Bm–G–Asus, baixo sincopado, marimba sintética, kick/conga/shaker,
motivos melódicos alternados e uma pequena abertura na quarta barra a cada duas
frases. O volume continua separado e discreto; isso é um protótipo procedural,
não uma gravação profissional. O agendamento usa o relógio do `AudioContext`
com lookahead curto, mantendo as frases contínuas mesmo quando o timer da aba
sofre atraso.

O cursor remoto usa `BoardView.matchId` e `RemoteEvent.seq`. O lote inicial é
considerado histórico, portanto reconectar/recarregar a TV não repete sons. Uma
partida nova zera o cursor sem reproduzir o primeiro lote. Eventos locais sem
`seq` são deduplicados por conteúdo. Moedas têm throttle de 180 ms para evitar
metralhar o alto-falante quando uma compra altera mais de um saldo.

Quando `stepKey` muda, o hook toca um passo somente se o áudio estiver ativado,
a aba visível e a partida sem pausa. O primeiro `stepKey` de um match é apenas
baseline. Com `visualSteps` (ou `stepKey`, que o ativa por padrão),
`movementFinished` não gera um segundo passo.

Uma prévia `state.pending.kind === 'cardPreview'` toca Sorte/Azar no início da
revelação, deduplicada por `matchId + playerId + cardId + revision`. Em partidas
digitais, o `cardResolved` correspondente é ignorado para não tocar a carta duas
vezes.

## Ciclo de vida e limites

- O `AudioContext` só é criado no primeiro `enable()`; não há autoplay.
- Partida pausada, aba oculta ou desmontagem suspendem/limpam nós e timers.
- O loop musical é opcional e começa em volume baixo (`0.2`); efeitos começam em `0.55`.
- O protótipo usa osciladores simples e pode ser substituído por samples locais no
  `audioEngine.ts`, mantendo o contrato do hook.
- O módulo é para a TV. O controle remoto/celular não deve montar `useGameAudio`.
